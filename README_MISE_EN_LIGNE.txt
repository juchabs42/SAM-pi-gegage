SAM PIÉGEAGE — VERSION À METTRE SUR GITHUB
============================================

Cette archive contient la version actuelle de SAM Piégeage avec :
- connexion identique à SAM Tavelure ;
- nouvelle icône SAM Piégeage dans l’onglet du navigateur ;
- nouvelle icône lors de l’ajout de l’application sur téléphone ;
- manifest Android / PWA ;
- favicon iPhone / iPad / navigateur.

À LA RACINE DE TON DÉPÔT GITHUB
--------------------------------
Remplace les fichiers existants par ceux de cette archive.

Fichiers principaux à REMPLACER :
- index.html
- style.css
- app.js
- config.js
- favicon.png

Fichiers à AJOUTER s’ils n’existent pas :
- favicon.ico
- apple-touch-icon.png
- android-chrome-192x192.png
- android-chrome-512x512.png
- icon-192-maskable.png
- icon-512-maskable.png
- site.webmanifest

Conserve également :
- logo-sudexpe.png

SUPABASE
--------
Aucune modification Supabase n’est nécessaire uniquement pour changer l’icône.

APRÈS LA MISE À JOUR GITHUB
---------------------------
1. Attendre le redéploiement GitHub Pages.
2. Sur ordinateur : Ctrl + F5.
3. Sur téléphone :
   - si SAM Piégeage était déjà ajouté à l’écran d’accueil, supprime l’ancien raccourci ;
   - ouvre de nouveau le site ;
   - ajoute-le à nouveau à l’écran d’accueil pour voir la nouvelle icône.
